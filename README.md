# 💙 SchoolVoice

**«Твой голос меняет школу»** — Telegram-бот для связи учеников с администрацией школы.

Python 3.11+ · aiogram 3 · SQLite (aiosqlite) · асинхронный

---

## Возможности

**Для учеников**

| Кнопка | Что делает |
|---|---|
| 📝 Отправить предложение | Текст → предпросмотр → можно исправить → отправка → номер обращения |
| ⚠️ Сообщить о проблеме | Категория (Столовая, Кабинеты, Санитарное состояние, Оборудование, Другое) → описание → отправка |
| 🗳️ Голосования | Активные и завершённые опросы, голосование, результаты с процентами. **Один голос на опрос** |
| 📨 Мои обращения | Свои обращения со статусами 🟡 На рассмотрении / 🔵 В обработке / 🟢 Решено и ответы администрации |
| 📊 Статистика | Общие цифры без личных данных |
| ℹ️ О проекте | Описание и правила |

Ученик получает уведомления, когда администрация отвечает или меняет статус обращения.

**Кабинет администрации** (кнопка «🛠 Админ-панель» или `/admin`, только для `ADMIN_IDS`)

- 📥 Просмотр всех обращений, отдельно предложений и проблем, фильтр по статусу, постраничный вывод
- ✍️ Ответ ученику (доставляется через бота; обращение автоматически переходит «В обработку»)
- 🔄 Изменение статуса с уведомлением автора
- 🗑 Удаление обращений (управление предложениями)
- ➕ Создание голосований с рассылкой всем или без неё
- 🗂 Завершение, возобновление и удаление голосований, просмотр результатов
- 📊 Подробная статистика (по типам, статусам, категориям, за день/неделю)
- 🔔 Уведомления о каждом новом обращении

## Безопасность

- Токен хранится только в `.env` (он в `.gitignore`), в коде его нет; токен не выводится в логи.
- Бот без корректного токена **не запускается** и выдаёт понятную ошибку.
- Админ-функции защищены фильтром `IsAdmin` на уровне всего роутера: обычный пользователь не может их вызвать даже через старые кнопки.
- Пользователь видит только **свои** обращения (проверка владельца при каждом открытии).
- По умолчанию администраторы тоже не видят имени автора (`SHOW_AUTHOR_TO_ADMINS=false`), ответ доставляется через бота.
- Повторное голосование невозможно: `PRIMARY KEY (poll_id, user_id)` в таблице `votes` плюс проверка в коде.
- Бот работает только в личных сообщениях: в группах он игнорирует сообщения, чтобы чужие данные никто не увидел.
- Антиспам: не больше `MAX_APPEALS_PER_DAY` обращений за 24 часа.
- Весь пользовательский текст экранируется перед выводом (HTML-разметка).

## Структура проекта

```
schoolvoice/
├── main.py            # точка входа, сборка диспетчера, обработчик ошибок
├── config.py          # чтение настроек из .env
├── constants.py       # тексты кнопок, статусы, категории, лимиты
├── database.py        # SQLite: схема и все запросы
├── keyboards.py       # reply- и inline-клавиатуры
├── callbacks.py       # фабрики callback-данных
├── states.py          # состояния FSM для диалогов
├── filters.py         # фильтр IsAdmin
├── middlewares.py     # регистрация пользователей в БД
├── utils.py           # форматирование, безопасная отправка, уведомления
├── handlers/
│   ├── __init__.py    # порядок подключения роутеров
│   ├── common.py      # /start, /help, /cancel, «О проекте»
│   ├── suggestions.py # предложения
│   ├── problems.py    # сообщения о проблемах
│   ├── polls.py       # голосования
│   ├── appeals.py     # «Мои обращения»
│   ├── stats.py       # статистика
│   ├── admin.py       # кабинет администрации
│   └── fallback.py    # необработанные сообщения и устаревшие кнопки
├── requirements.txt
├── .env.example
└── README.md
```

База данных создаётся автоматически при первом запуске в `data/schoolvoice.db`.
Таблицы: `users`, `appeals` (предложения и жалобы, поле `type`), `responses` (ответы администрации), `polls`, `poll_options`, `votes`.

## Установка и запуск

### 1. Получите токен и свой ID

1. В Telegram откройте **@BotFather** → `/newbot` → задайте имя (например, *SchoolVoice*) и username. Скопируйте токен.
2. Откройте **@userinfobot** и узнайте свой числовой ID. Это ID администратора.
3. По желанию в @BotFather: `/setuserpic` (бело-голубая аватарка), `/setdescription` («Твой голос меняет школу»).

> Токен — это пароль от бота. Не пересылайте его никому и не публикуйте.

### 2. Установите зависимости

Нужен Python **3.11 или новее** (`python --version`).

**Windows (PowerShell):**
```powershell
cd путь\к\schoolvoice
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

**macOS / Linux:**
```bash
cd путь/к/schoolvoice
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

### 3. Заполните `.env`

Откройте файл `.env` в любом текстовом редакторе:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789,987654321
```

Остальные параметры можно оставить по умолчанию.

### 4. Запустите бота

```bash
python main.py
```

В консоли появится `Бот @ваш_бот запущен`. Откройте бота в Telegram и отправьте `/start`.
Остановить бота: `Ctrl+C`.

## Параметры `.env`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `ADMIN_IDS` | пусто | ID администраторов через запятую |
| `DB_PATH` | `data/schoolvoice.db` | Путь к базе данных |
| `TIMEZONE` | `Asia/Tashkent` | Часовой пояс для дат |
| `MAX_APPEALS_PER_DAY` | `10` | Лимит обращений за 24 часа (`0` — без лимита) |
| `SHOW_AUTHOR_TO_ADMINS` | `false` | Показывать ли администраторам имя автора |
| `LOG_LEVEL` | `INFO` | Уровень логирования |

## Частые вопросы

- **«Ошибка настройки: Не задан BOT_TOKEN»**: нет файла `.env` или токен не вписан.
- **«Telegram отклонил токен»**: токен неверный или отозван, получите новый в @BotFather (`/token`).
- **Нет кнопки «🛠 Админ-панель»**: проверьте свой ID в `ADMIN_IDS`, перезапустите бота и отправьте `/start`.
- **Незавершённые диалоги сбрасываются после перезапуска**: состояния хранятся в памяти. Все сохранённые данные (обращения, голоса) остаются в базе.
- **Резервная копия**: достаточно скопировать файл `data/schoolvoice.db` (лучше при остановленном боте).
